## 得分之外的检查

唯一的退步题为 `GIS/2018/page_110.pdf-2`：新版把经营租赁和资本租赁一起计入分子、分母，而基准采用另一取数范围。这说明算术、引用和执行验证通过后，取数口径仍可能出错。

两道未得分题返回 `insufficient_evidence`，属于完成运行后的拒答，仍按答错计分；其余六道给出数值但与基准不一致。个别题的题意、年份或参考程序存在不一致，原始标签全部保留，未按主观判断修改分数。

| 未得分题 | 轨迹和原始资料揭示的问题 |
| --- | --- |
| CDW/2015/page_93.pdf-2 | 模型把费用问题理解为净利润/EPS并拒答，漏掉正文的退休计划费用；参考公式本身也有分子分母方向疑点 |
| DVN/2012/page_77.pdf-1 | 模型算两年到期债务占总债务，参考程序算两年之间的金额比并乘 100，问题解释及尺度不同 |
| GIS/2018/page_110.pdf-2 | 唯一退步：模型合并经营与资本租赁，参考只用经营租赁 |
| GPN/2008/page_78.pdf-1 | 模型因“最长 14 年”不等于确定寿命而拒答；参考直接使用 4091/14，拒答仍算错 |
| GPN/2010/page_89.pdf-4 | 可见表中上一期公允价值为 42，参考程序使用 41，存在操作数不一致 |
| KHC/2018/page_132.pdf-2 | 模型用 2.7/31.2，参考用 2.7/(31.2+2.7)，偿还比例基数不同 |
| SNA/2012/page_110.pdf-1 | 模型按百分比变化计算；参考程序做两次减法得到 -905，与题意存在明显冲突 |
| SNA/2012/page_110.pdf-3 | 模型用股数乘每股价格；参考程序将两者相减，存在量纲疑点 |

这些原因用于错误分析，不构成重标注后的“更高准确率”。有疑点的题也全部按原始基准计分。

两道由错变对的案例尤其需要保留语义风险说明：

- `PNC/2012/page_68.pdf-2`：新版数值命中基准，但解释承认题目所问 2008/2009 年不在材料内，转用了 2011/2012 年。
- `AMT/2016/page_49.pdf-1`：题目问股价从最高到最低的百分比变化，新解释按最低到最高计算，并得到基准要求的正值。

这两题属于**基准判对但金融语义仍有风险**，不能把 8 道得分改善全部视为真实业务判断改善。它们在公布的 42/50 中仍按原基准判分，没有悄悄替换标签或另设有利评分。

上述分析来自已完成轨迹，不用于改写本轮技能或提示词。84% 是这 50 题的一次配对回归成绩；样本存在同源相关性，不能直接推断全 FinQA 或生产金融任务的准确率，也没有证明自动学习技能带来了收益。
