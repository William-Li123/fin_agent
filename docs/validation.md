## 学习闭环的实际边界

真实提案归纳出一条流程：计算增幅前先明确指定期间与每个数字的对应关系，避免把另一组期间的数字带入分母。生成过程不包含参考答案；候选不含具体年份、金额和题目 ID。

首次提案因触发词格式不合规而失败，该请求费用仍计入账本。随后补齐字段限制、原始响应/校验错误留档，以及最多一次明确计费的结构修复。修复后的真实提案一次通过格式检查。

独立验证没有证实准确率提升，所以候选继续留在隔离区。此轮只证明“能从真实失败提炼方法并运行验证/拒绝流程”；**没有证明自动生成技能能普遍提高准确率**。通过验证后的晋升、历史版本和回滚路径由确定性测试覆盖，尚无真实 API 验证获批的学习技能。
