# Fin Agent 工作台

围绕会话、资料、执行过程和研究产物的 React + TypeScript 前端。界面参考 Codex 的工作台布局，新会话不附带资料，上传真实文档后由现有 Agent 分析。上传和预览不会调用模型；提交问题使用服务端密钥和共享预算。

## 本地开发

先在仓库根目录启动 `finagent web` 后端（默认 `127.0.0.1:8000`），再在本目录执行：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`。Vite 将 `/api` 代理到本地后端。前端不会保存、显示或接收模型 API Key。

## 构建

```sh
npm run build
```

产物位于 `dist/`，由 Python 后端在同一地址提供。生产环境使用同源 `/api` 请求，无需单独部署前端。

## 交互

- 新分析支持 `Ctrl/Cmd + N`；输入框按 `Enter` 发送、`Shift + Enter` 换行，中文输入法组词时不会发送。
- 资料库负责上传、选择和预览资料。真实分析要求后端已配置密钥与有效共享预算。
- 右侧面板展示实际执行事件与当前会话的报告、图表；引用可打开原始证据。
- 运行中的停止为协作式停止：当前操作结束并完成费用结算后停止。
- Skills 页面只读展示能力目录、完整方法和隔离的学习候选。真实模式「提炼经验」可额外调用模型，费用计入共享预算。
- 本地浏览器只保存有版本号的界面偏好（主题、最近会话 ID）。会话、资料、运行与预算由后端持久保存。

## 浏览器验证

```sh
npx playwright install chromium
npm run test:e2e
```

先安装 Python 的 Web 扩展并构建 `dist/`。测试自动在 8011 端口启动后端，使用隔离的无预算状态目录和空 API Key。可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定本机 Chromium 浏览器路径；详细启动方法参见仓库根目录文档。
